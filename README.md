# krx-market-mcp

KRX OpenAPI(정보데이터시스템) 인증키 하나로 이용 승인된 **17개 API 전부**를 실시간 조회하는 MCP 서버입니다.
저장소는 두지 않고 매번 KRX를 호출합니다(과거 날짜 응답만 인스턴스 메모리에 잠시 캐시).

## 도구

| 도구 | KRX API | 기능 |
|---|---|---|
| `krx_list_listed` | 유가증권·코스닥·코넥스 종목기본정보 | 상장 종목 목록 + 시장별 회사 수 집계(보통주·영업 회사) |
| `krx_get_stock_daily` | 유가증권·코스닥·코넥스 일별매매정보 | 종목 시세·시가총액, 시장 합계, 기본정보 결합 |
| `krx_get_index_daily` | KRX·KOSPI·KOSDAQ 시리즈 일별시세, 채권지수 시세 | 지수 시세 |
| `krx_get_etf_daily` | ETF 일별매매정보 | NAV·순자산·기초지수 |
| `krx_get_bond_daily` | 국채전문유통·일반채권·소액채권 일별매매정보 | 채권 시세·수익률 |
| `krx_get_commodity_daily` | 석유·금·배출권 일별매매정보 | 일반상품 시세 |
| `krx_get_timeseries` | 일별 API 14종 공통 | 종목·지수의 기간 시세(일/주/월) |
| `krx_api_status` | — | 설정 상태·데이터셋 안내·전 API 실호출 점검 |

필드별 명세서 설명과 서버 라벨 대조표: [docs/krx-api-fields.md](docs/krx-api-fields.md) (승인 17종 + 미승인 5종)

## 회사 수 집계 규칙

- 회사 수 = 주식종류 `보통주` 종목 수
- 영업 회사 = 보통주 − 리츠(부동산투자회사) − 인프라펀드(사회간접자본투융자회사) − 투자회사 − 스팩
- 스팩 = 소속부 `SPAC…` **또는** 종목명 `기업인수목적` **또는** 약명 `스팩` (관리종목 지정 스팩은 소속부가 `관리종목(소속부없음)`으로 바뀌어 있음. "스팩"은 종목명이 아니라 약명에만 있음)
- 외국주권·주식예탁증권은 회사로 셈

검증값(기준일 2026-10-06): 코스피 942/831/805, 코스닥 1,824/1,821/1,750(스팩 71), 코넥스 107/107/107 — `npm test`가 이 값을 확인합니다.

## KRX API 특성 (2026-10-07 실측)

- 매매·지수 API는 휴장일·당일·**형식이 틀린 날짜**에 모두 HTTP 200 + 빈 배열을 줍니다. 서버는 날짜 형식을 먼저 검사하고, 빈 배열이면 최대 10일 거슬러 조회해 실제 사용일을 응답에 표시합니다.
- 종목기본정보는 주말·공휴일에도 그날 기준 스냅샷을 주고, 당일·미래만 빈 배열입니다.
- 제공 시작일: 주식·지수·ETF·채권 2010-01-04, 코넥스 2013-07-01, 석유 2012-03-30, 금 2014-03-24, 배출권 2015-01-12.
- 종목기본정보의 `ISU_CD`는 12자리 표준코드, 일별매매의 `ISU_CD`는 6자리 단축코드입니다. 결합 키는 기본정보 `ISU_SRT_CD` ↔ 매매 `ISU_CD`.

## 환경변수

| 이름 | 내용 |
|---|---|
| `KRX_AUTH_KEY` | KRX OpenAPI 인증키 |
| `MCP_GATE_KEYS` | 허용 게이트키 목록(쉼표 구분) |
| `MCP_GATE_MODE` | `enforce` |

엔드포인트: `https://<도메인>/api/mcp?k=<게이트키>`

## 테스트

```
KRX_AUTH_KEY=... npm test          # 전 도구 실호출
KRX_AUTH_KEY=... node smoke.mjs krx_list_listed   # 일부만
```
